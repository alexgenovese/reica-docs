# Use Cases

Real workflows from fashion, beauty and lifestyle brands using Reica today.

---

## 1. E-commerce product catalogue

**Challenge:** A fashion brand needs 400+ product images for their new seasonal collection — ghost mannequin and flat lay for every SKU, consistent lighting, white background.

**With Reica:**
1. Upload each product (front + back) to the Library
2. Open Still Life, set Output Type to **Ghost** or **Flat Lay**, white background
3. Use **Batch Operations** to process all SKUs at once
4. Download at 4K, ready for the PDP

**Result:** Entire seasonal catalogue produced in hours, not weeks. No studio rental, no post-production team.

---

## 2. Campaign with a consistent model

**Challenge:** A beauty brand wants a full spring campaign — social posts, email header, website hero — all featuring the same model, different looks.

**With Reica:**
1. Create a **Character** in the Character module (or pick from Reica's library)
2. Open a **Board**, add the hero garment as the starting node
3. Generate variations with different photographic styles (editorial, natural, studio)
4. The same character appears in every output — face, proportions, skin tone identical

**Result:** A consistent brand campaign across all channels produced in under a day.

---

## 3. Influencer-level content without the influencer

**Challenge:** A lifestyle brand produces 30+ social posts per month. Hiring models and photographers for every shoot is unsustainable.

**With Reica:**
1. Build a character that matches the brand's visual identity
2. Use Still Life for product-focused shots
3. Use Board for lifestyle compositions
4. Export directly at social dimensions

**Result:** 30 publication-ready posts per month with a single team member. Consistent aesthetic, zero coordination overhead.

---

## 4. Try-on campaign for a new collection

**Challenge:** A fashion brand is launching a 20-piece collection and needs editorial try-on shots for the lookbook.

**With Reica:**
1. Upload the 20 garments to the Library
2. Select the brand's saved Character
3. Apply a consistent photographic style in Board
4. Generate all 20 looks in one session

**Result:** A complete lookbook in a fraction of traditional shoot costs, with every image sharing the same editorial quality.

---

## 5. Seasonal product refresh

**Challenge:** A cosmetics brand re-launches 50 existing SKUs with new packaging and needs updated campaign imagery across e-commerce and social.

**With Reica:**
1. Upload the new product images
2. Select saved background and lighting settings from the last campaign
3. Run Batch Operations to regenerate all 50 assets at once
4. Export at the required dimensions for each channel

**Result:** Brand consistency maintained across the refresh. All 50 SKUs updated in a single afternoon.
